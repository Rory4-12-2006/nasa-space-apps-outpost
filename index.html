NASA DATA SOURCES

REAL vs. SIMPLIFIED!

Real: event dates, flare classes, CME speeds, radiation measured by Curiosity on Mars and Chang'e-4 on the Moon, the 2018 Mars dust storm, message delay to Earth.

Simplified for play: bar sizes, how much each building makes, how long a Sol lasts in the game, and how radiation turns into Crew Health points.

LIVE = fetched from NASA today. ARCHIVE = real past data stored in the game. OFFLINE = live data could not load, so we used the archive.
