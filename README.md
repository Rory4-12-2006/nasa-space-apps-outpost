# Mars: Sols of Survival (NASA Space Apps Cairo 2026)

A browser game for kids ages 7–12. You run a small Mars outpost, and each Sol a real space-weather event from NASA data hits the base. You choose between sheltering and working, building walls or growing food, and asking Earth for advice that may arrive too late. Every choice has a cost.
